# ix1 Branding

## Mark

The official ix1 logo is a stylized geometric "X" with a crown/arrow
crown element above it — black mark on white (light) and white mark on
black (dark).

Source assets (JPEG exports of the official marks):

- `brand/logo-light.jpeg` — black mark on white background (light use)
- `brand/logo-dark.jpeg` — white mark on black background (dark use)

PNG/SVG derivatives should be produced for UI use (icon theme, installer,
website, ISO boot splash). Until then, JPEGs are the source of truth.

## Usage

- Product name: `ix1` (lowercase) in text; the X mark for icons/splash.
- The mark is monochrome; do not recolor arbitrarily.
- Minimum clear space: height of the crown element on all sides.
- Do not stretch, rotate, add effects, or place on busy backgrounds
  without the appropriate light/dark variant.

## System identity

- Hostname: `ix1`
- OS release string: `ix1` (PRETTY_NAME set via os-release in M1 follow-up)
- Desktop shell name: `ix1-shell`
